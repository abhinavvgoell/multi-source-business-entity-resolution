05 / REPRODUCE

Run it locally.

Install NumPy, use the challenge data folder, then train, evaluate, and predict. The portfolio page itself is dependency-free.

cd student_resource
pip install -r code/business_entity_resolution/requirements.txt
python code/business_entity_resolution/src/business_entity_resolution.py train --data dataset --model model/entity_matcher.json
python code/business_entity_resolution/src/evaluate_holdout.py --data dataset --model model/entity_matcher.json --eval-size 500 --streaming-references --report results/fresh_holdout_500.json
python code/business_entity_resolution/src/business_entity_resolution.py predict --data dataset/test --model model/entity_matcher.json --output output --max-candidates 80
